# Jogos de História

Jogos de revisão de História para o Ensino Médio (Provão Paulista), da Profª Andréa Vanessa Borges Vilela.

- `index.html`: página inicial com todos os jogos
- `roleta.html`: Roleta da História (para projetar, em equipes)
- `escape-room.html`: Escape do Arquivo Histórico (para projetar)
- `quiz-1-serie.html`, `quiz-2-serie.html`, `quiz-3-serie.html`: quizzes para estudar no celular

É um site estático: não precisa de instalação nem de build.
